# 🤖 JARVIS — Personal AI Voice Assistant

> A Python-based personal AI assistant built to interact through voice commands, AI-powered conversations, automation, and computer vision.

---

## 🧠 About JARVIS

**JARVIS** is my main Python project — a personal AI voice assistant inspired by futuristic virtual assistants.

The project combines **Python, speech recognition, AI APIs, automation, OpenCV, and a custom interface** to create an interactive desktop assistant.

Instead of being just a chatbot, JARVIS is designed to **listen, understand, respond, and perform actions** on the computer.

---

## ✨ Features

### 🎙️ Voice Interaction
- Voice command recognition
- Converts speech into commands
- Responds using text-to-speech
- Displays recognized commands on the interface

### 🤖 AI Intelligence
- AI-powered question answering
- Natural-language interaction
- General knowledge queries
- AI-generated responses

### 🌐 Automation
- Open websites using voice commands
- Launch commonly used services
- Perform predefined computer actions
- Voice-controlled navigation

### 🔐 Face Authentication
- Real-time camera-based face detection
- Face authentication before accessing JARVIS
- Password fallback
- Access control system

### 💤 Sleep & Wake System
- Put JARVIS into sleep mode
- Wake the assistant using a command
- Helps control when the assistant is actively listening

### 🖥️ Custom Interface
- Futuristic AI-inspired interface
- Displays recognized commands
- Displays JARVIS responses
- Camera integration
- System information
